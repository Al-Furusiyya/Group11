## Integration preserved and measured performance

Byte comparison against v1 confirms the working app/link/protocol, Tcl host,
CPU/JTAG/firmware, top wiring, QPF/QSF, pins and SDC are unchanged. Only the three
runtime files in `SMOOTH_UPDATE.md` differ.

A development-container benchmark over 60 simulated seconds / 1,800 updates
(NB left, NB WALK, WB WALK at 30 updates/s) measured **0.987 ms mean, 3.158 ms
p95, 6.147 ms maximum** per controller update. It excludes the USB-Blaster,
Quartus process and physical monitor. It is not a host throughput guarantee.
The interpolation scheduler finishes its forty-coordinate update in 0.8 µs
of CLOCK_50 cycles during vertical blank, as exercised in RTL simulation.

## Remaining hardware checks

Quartus compilation, fitting, TimeQuest review, new SOF programming and physical
VGA/PS2/USB-Blaster acceptance remain to be done on your PC and board. No Quartus
executable or physical DE1-SoC is available here. Generic Yosys checks do not
produce an Intel ALM utilization count or prove routed timing.

The original working upload used 5,564 / 32,070 ALMs and 46 pins; these are
**historical baseline counts**, not v2 utilization. The adaptive renderer adds
fractional registers/shared arithmetic and requires a fresh fit.

The model uses scaled demo timings and simplified cars. The finite tests cover
the cases above, not every possible input history or real roadside certification.
A host stall can still limit animation: interpolation completes known targets
and holds rather than guessing a car's next position.

## Reproduce

With Icarus Verilog (`iverilog`, `vvp`) and `tclsh` on PATH:

```powershell
python .\sim\check.py
```

Python only:

```powershell
python -m unittest discover -s sim -p "test_*.py" -v
```

Current actual scene captures:

```powershell
iverilog -g2005 -s tb_vga_capture -o sim/vga_capture.vvp vga_scene.v sim/tb_vga_capture.v
vvp sim/vga_capture.vvp
```

Optional software references and fixture generation (Pillow/NumPy):

```powershell
python .\sim\render_preview.py
```

Follow `START_HERE.md` to full-compile/program and perform board acceptance.
